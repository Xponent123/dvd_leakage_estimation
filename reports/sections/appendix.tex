\section{Reproduction and file map}
\label{sec:app}

Paths are relative to the repository root (\url{https://github.com/Xponent123/dvd_leakage_estimation}).

\textbf{Re-running.}
\begin{itemize}
\item \texttt{bash run.sh setup}: install the Python dependencies and ngspice 42.
\item \texttt{bash run.sh verify}: check file hashes, saved models, gate and circuit sums and the report sources. It runs no SPICE.
\item \texttt{bash run.sh analysis}: regenerate \texttt{results/analysis/} and \texttt{reports/figures/analysis/} from the stored results (no SPICE, no training).
\item \texttt{bash run.sh reproduce}: full regeneration into \texttt{code/reproduced/} (hours, needs ngspice).
\item \texttt{bash run.sh report}: compile this report with pdfLaTeX.
\end{itemize}
Fixed seeds are recorded in the manifests.
